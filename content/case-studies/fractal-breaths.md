# Fractal Breaths

**Category:** Prototype
**Hiring audience:** Creative Technologist, AI Prototyper, Experience Designer, Forward Deployed Creative

---

## One-line thesis
A browser-based generative meditation engine — built in hours using AI-assisted coding — that responds to the user's own breathing rhythm.

---

## Context
Fractal Breaths is a rapid prototype exploring two things at once: embodied interface design (can a browser experience genuinely support breathing practice?) and AI-assisted development (how fast can a concept become a working prototype with AI coding tools?).

---

## Problem / Challenge
Can a browser experience genuinely respond to a user's own rhythm — not a pre-set timer, but breath controlled by the person using it? And can that experience hold up visually on a projector or big screen, not just a laptop?

---

## My Role
- Design and UX concept
- Frontend build (React, Web Audio API)
- Audio and interaction logic
- Deployment (Netlify)

---

## Process
1. Concept — breathing app as a generative visual engine, not a static timer
2. AI-assisted prototyping — used Google AI Studio + Cursor to accelerate from idea to working code
3. Visual system — procedural patterns that respond to breath phase (inhale, hold, exhale, rest)
4. Audio system — ambient soundscapes via Web Audio API
5. UX refinement — user-controlled durations, color/B&W modes, projector-friendly layout
6. Deployment — live on Netlify

---

## Tools / Workflow
- **Prototyping:** Google AI Studio, Cursor
- **Frontend:** React
- **Audio:** Web Audio API
- **Deployment:** Netlify

---

## Output
A fully functional, live browser app at fractal-breaths.netlify.app with:
- User-controlled inhale / hold / exhale / rest durations
- Five visual patterns
- Six ambient soundscapes
- Color and black-and-white modes
- Projector / fullscreen mode
