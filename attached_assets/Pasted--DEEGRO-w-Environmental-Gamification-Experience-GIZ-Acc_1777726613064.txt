**DEEGRO.w! — Environmental Gamification Experience**

*GIZ Accelerator Programme 2023-24 | 1 of 6 teams selected from 25 | €10K funded*

## Project Overview

Designed and prototyped an **interactive gamification experience** that translates complex environmental systems into engaging gameplay, winning the Audience Choice Award for innovation and user impact.

**The Challenge:** Create an engaging tool to raise environmental awareness and motivate behavioral change around climate issues.

**The Solution:** A role-playing game where players manage resources, make decisions with real consequences, and see the direct impact of their choices on ecosystem health.

## Rapid Prototyping Process

**LoFi → MidFi → HiFi Development (6 months)**

- Started with board game concept for quick user testing
- Iterated based on co-creation sessions and contextual feedback
- Scaled to mobile game design with enhanced interactivity
- Developed multiple user flows and ending scenarios

## Key Skills Applied

**UI/UX Design**

- User journey mapping for multiple player roles
- Interactive feedback systems (resource meters, event notifications)
- Visual storytelling through game interface
- Accessibility considerations for rural communities

**Prototyping & Iteration**

- Rapid concept-to-prototype pipeline
- User testing and feedback integration
- Cross-platform thinking (physical → digital)
- Modular design for scalability

**Innovation & Experimentation**

- Gamification mechanics for behavior change
- Data visualization (results grid for group discussion)
- Multi-role system design (Mayor, Ambassador, CEO, Contractor)
- Translating complex systems into intuitive interactions

## Impact

- Won competitive public vote (Audience Choice Award)
- Advanced through 3-phase accelerator program
- Pitched to expert jury and secured advancement pathway
- Designed for scalable deployment across African communities
